# Phase 1 — Setup Project + Design Tokens

Ghi lại chi tiết toàn bộ những gì đã làm, lý do quyết định, và quy tắc để scale về sau.

---

## 1. Bối cảnh

`frontend/` ban đầu chỉ có `README.md`, `main.css`, `design-system/`, `docs/` — chưa có Next.js project.  
Mục tiêu Phase 1: **dựng Next.js, cấu hình toàn bộ design token từ MASTER.md, không có hex nào trong component.**

---

## 2. Lệnh đã chạy

### 2.1 Tạo Next.js project

```bash
# Vì frontend/ không rỗng, tạo vào thư mục tạm trước
npx -y create-next-app@latest ./frontend/app-temp \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir \
  --import-alias "@/*" \
  --use-npm \
  --disable-git \
  --yes

# Move toàn bộ ra frontend/, giữ nguyên design-system/ và docs/
rsync -av \
  --exclude='design-system/' \
  --exclude='docs/' \
  --exclude='README.md' \
  --exclude='main.css' \
  frontend/app-temp/ frontend/

# Dọn thư mục tạm
rm -rf frontend/app-temp
```

**Kết quả:** Next.js **16.4.5** + React **19** + Tailwind **4** + TypeScript **5** + ESLint **9**.

### 2.2 Chạy dev server (để verify)

```bash
cd frontend
npm run dev
# → http://localhost:3000
```

## 3. File đã viết / sửa

### 3.1 `src/app/globals.css` — Nơi duy nhất chứa hex

```css
@import "tailwindcss";

@import url('https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;0,500;0,600;1,400;1,500&family=Jost:wght@300;400;500&display=swap');

@theme {
  /* 14 color tokens từ MASTER.md */
  --color-brand-background:    #EDE7DA;
  --color-brand-card:          #F4F1E9;
  --color-brand-surface:       #D6CFB0;
  --color-brand-foreground:    #4A4535;
  --color-brand-muted:         #655F4D;
  --color-brand-border:        #A09A8A;
  --color-brand-input-border:  #7A7461;
  --color-brand-on-foreground: #EDE7DA;
  --color-brand-on-image:      #FFFFFF;
  --color-brand-lavender:      #D1C3DC;
  --color-brand-peach:         #F2D1BC;
  --color-brand-gold:          #EBB658;
  --color-brand-sage:          #B6C09D;
  --color-brand-ring:          #4A4535;

  /* Fonts */
  --font-serif: 'Cormorant Garamond', Georgia, serif;
  --font-sans:  'Jost', system-ui, sans-serif;

  /* Spacing scale */
  --spacing-xs:  4px;   /* tight gaps */
  --spacing-sm:  8px;   /* inline */
  --spacing-md:  16px;  /* standard padding */
  --spacing-lg:  24px;  /* paragraph / form */
  --spacing-xl:  48px;  /* block gaps */
  --spacing-2xl: 96px;  /* section padding */

  --radius: 0; /* square corners toàn project */
}

@layer base {
  html {
    background-color: var(--color-brand-background);
    color: var(--color-brand-foreground);
    font-family: var(--font-sans);
    -webkit-font-smoothing: antialiased;
  }
  h1, h2, h3, h4, h5, h6 {
    font-family: var(--font-serif);
    letter-spacing: 0.05em;
  }
  :focus-visible {
    outline: 2px solid var(--color-brand-ring);
    outline-offset: 2px;
  }
}
```

**Tại sao dùng `@theme` thay vì `tailwind.config.ts`?**  
Tailwind v4 bỏ file config JS — tất cả token khai báo trong CSS qua `@theme {}`.  
Tailwind tự sinh ra các class `bg-brand-background`, `text-brand-foreground`... từ đó.

### 3.2 `src/app/layout.tsx` — Root layout

```tsx
import type { Metadata } from "next";
import "./globals.css";

export const metadata: Metadata = {
  title: "LUA Studio — Cho thuê áo dài editorial",
  description: "LUA Studio — boutique cho thuê áo dài editorial.",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="vi">
      <body>{children}</body>
    </html>
  );
}
```

Font **không** dùng `next/font/google` vì Tailwind v4 load font qua `@import url(...)` trong CSS — đơn giản hơn, không cần truyền className.

### 3.3 `src/app/page.tsx` — Trang verify token

Trang tạm để xác nhận tất cả 14 token render đúng màu — sẽ bị replace ở Phase 3 (Homepage).  
Quy tắc bắt buộc: **không có hex nào trong file này**, chỉ dùng class Tailwind `brand.*`.

## 4. Quy tắc Token — Scale về sau

### 4.1 Luật vàng: hex chỉ được phép ở 1 nơi

| Nơi | Được phép hex? |
|-----|---------------|
| `src/app/globals.css` → `@theme {}` | ✅ Có — đây là nơi duy nhất |
| `tailwind.config.ts` | ✅ Có (nếu dùng Tailwind v3) |
| Bất kỳ component `.tsx` nào | ❌ Không bao giờ |
| `style={{ color: '#...' }}` inline | ❌ Không bao giờ |
| File CSS khác (ví dụ: `button.module.css`) | ❌ Không — dùng `var(--color-brand-*)` |

### 4.2 Cách dùng token trong component

```tsx
// ✅ Đúng — dùng Tailwind class sinh từ token
<div className="bg-brand-surface text-brand-foreground">

// ✅ Đúng — dùng CSS variable khi cần inline
<div style={{ backgroundColor: 'var(--color-brand-surface)' }}>

// ❌ Sai — hardcode hex
<div className="bg-[#D6CFB0]">
<div style={{ backgroundColor: '#D6CFB0' }}>
```

### 4.3 Thêm token mới

Chỉ cần thêm vào `@theme {}` trong `globals.css`:

```css
@theme {
  --color-brand-new-token: #XXXXXX;
}
```

Tailwind tự sinh class `bg-brand-new-token`, `text-brand-new-token`, `border-brand-new-token`...

### 4.4 Thay đổi màu (rebrand / A-B test)

Chỉ cần đổi giá trị hex trong `globals.css` → toàn bộ component cập nhật theo.  
Không cần tìm/thay trên hàng chục file.

## 5. Quyết định kỹ thuật & Lý do

| Quyết định | Lý do |
|------------|-------|
| **Next.js App Router** (không Pages Router) | Standard hiện tại, Server Components giúp giảm JS bundle |
| **Tailwind v4** (`@theme` trong CSS) | v4 là mặc định của `create-next-app` mới nhất; không dùng file config JS |
| **Google Fonts qua `@import` CSS** | Tailwind v4 load font trong CSS — đơn giản hơn `next/font` trong trường hợp này |
| **`src/` directory** | Tách code khỏi config ở root, dễ navigate khi project lớn |
| **`@/*` import alias** | Tránh relative path `../../..` lồng nhau khi component nằm sâu |
| **`--disable-git`** | Project đã có git ở root `retail-system/`, không tạo git mới bên trong |
| **Light mode only** | Quyết định từ MASTER.md — phong cách boutique không phù hợp dark mode |
| **Square corners (`--radius: 0`)** | Quyết định từ MASTER.md — editorial minimalism |
