# Phase 2 — Module Architecture + Base Components

Ghi lại chi tiết toàn bộ những gì đã làm trong Phase 2: cấu trúc module, từng component, quyết định kỹ thuật, lỗi gặp phải và cách xử lý.

---

## 1. Mục tiêu

Xây dựng **skeleton scalable** của toàn bộ frontend:
- Cấu trúc thư mục chuẩn hoá
- Base atoms (`ui/`) dùng token màu
- Layout components (`layout/`)
- Block stubs (`blocks/`) với interface đúng TypeScript
- Route stubs cho tất cả pages trong ROADMAP

## 4. Chi tiết từng file

### 4.1 `lib/utils.ts` — `cn()` helper

```ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

**Tại sao cần cả clsx lẫn tailwind-merge?**
- `clsx` — xử lý conditional class names (object, array, falsy values)
- `tailwind-merge` — resolve conflict khi 2 class cùng property (ví dụ `bg-brand-surface` bị override bởi `bg-brand-foreground`, cái sau thắng)
- Nếu chỉ dùng template literal `className={\`base ${condition ? 'extra' : ''}\`}` → conflict không được resolve, Tailwind sẽ apply cả 2 theo cascade không đoán trước được

### 4.2 `lib/constants.ts`

Chứa `NAV_LINKS` và `STUDIO_INFO` — **single source of truth** cho nav order và thông tin studio.

> **Scale note:** Nav order phải đúng: `Home · Shop/Collection · How to Rent · Size Guide · FAQs · Contact`. Thay đổi order → chỉ sửa 1 chỗ ở đây, Header và Footer tự cập nhật.

## 5. Lỗi gặp phải và cách xử lý

### Lỗi #1 — `lucide-react` không có brand icons

```
Error: Export Instagram doesn't exist in target module
```

**Nguyên nhân:** `lucide-react` chỉ chứa UI icons, không có brand/social icons (Instagram, Facebook, TikTok...).

**Fix:** Cài `react-icons` và dùng `react-icons/fa6`:
```tsx
import { FaInstagram as Instagram, FaFacebook as Facebook } from "react-icons/fa6";
```

**Rule về sau:** `lucide-react` = UI chrome icons · `react-icons/fa6` = brand social icons.

### Lỗi #2 — `new Date()` trong Server Component

```
Error: Next.js encountered the unstable value `new Date()` while prerendering.
```

**Nguyên nhân:** Next.js 16 prerender tĩnh Server Components — `new Date()` là giá trị dynamic bị chặn.

**Fix:** Hardcode năm `2026` trong Footer. Copyright year là giá trị tĩnh, không cần dynamic per request.

**Rule về sau:** Trong Server Component, không dùng `new Date()`, `Math.random()`, hay bất kỳ giá trị thay đổi theo thời gian. Muốn dynamic → `"use client"` hoặc `await connection()`.

### Lỗi #3 — `frontend/src/lib/` bị git ignore

**Nguyên nhân:** Root `.gitignore` có `lib/` từ Python template → vô tình ignore `frontend/src/lib/`.

**Fix:** Thêm exception `!frontend/src/lib/` vào root `.gitignore`.

**Rule về sau:** Khi thêm thư mục mới có tên trùng với Python build artifacts (`lib`, `dist`, `build`...) → check `.gitignore` ngay.

## 6. Quyết định kỹ thuật

| Quyết định | Lý do |
|------------|-------|
| `"use client"` chỉ ở components có state | Giữ tối đa Server Components — ít JS bundle hơn |
| Stub với interface đúng TypeScript ngay từ đầu | TypeScript báo lỗi ngay khi Phase sau truyền data sai type |
| `Section.tsx` wrap mọi section | Thay đổi layout global → 1 file duy nhất |
| Logo Header dùng `absolute + translate` | Giữ logo truly centered kể cả khi số link hai bên không bằng nhau |
| `PriceBreakdown` nhận `breakdown: PriceBreakdown \| null` | Null state hiển thị placeholder — không render giá 0 gây nhầm lẫn |
| `Intl.NumberFormat` cho giá VND | Format đúng locale, không hardcode format string |
