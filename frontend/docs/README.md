## Quy ước tài liệu

- YAML front matter đầy đủ ở đầu file.
- Bảng **Lịch sử thay đổi** ở cuối file.
- Link nội bộ dùng đường dẫn tương đối.
- Không có secret, hex hardcode, hay đường dẫn tuyệt đối.
